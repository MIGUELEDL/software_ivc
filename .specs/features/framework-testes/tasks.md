## Phase Execution Map

Visual representation of task ordering. Phases run in sequence, and tasks within a phase run in order:

```
Phase 1 → Phase 2 → Phase 3

Phase 1:  T1 (fundação)
Phase 2:  T1 → T2 → T7
Phase 2:  T1 → T3 → T7
Phase 2:  T1 → T4 → T7
Phase 2:  T1 → T5 → T7
Phase 2:  T1 → T6 → T7
Phase 3:  T7 → T8 → T9
```

Execution is strictly sequential - there is no intra-phase parallelism. A single agent (or batch worker) works one task at a time, in order.

**Packing**: 9 tasks → 2 batches de fase inteira (P1+P2 = 7 tasks; P3 = 2 tasks). Um worker por batch; ~7 tasks/batch é o sweet spot. O orchestrator oferece sub-agenciar o batch 1 dentro do mesmo fluxo se o usuário aceitar.
